## 业务术语

| 我说 | 意思是 |
|---|---|
| 抖店 / 小店 | 抖音小店后台 `fxg.jinritemai.com` |
| 千川 | 巨量千川，抖音的付费广告投放平台 |
| 体验分 | 抖店体验分，百分制，**480 分是隐形限流分水岭** |
| 商品卡 | 抖音商城「猜你喜欢」等货架场景的免费流量 |
| 精选联盟 | 抖音的达人分销平台（CPS 模式） |
| 达人分销 / CPS | 达人带货，成交后才付佣金，零风险 |
| 飞鸽 | 抖店客服 IM 工具 |
| 罗盘 | 抖音电商数据后台 |
| 主推款 | 我重点投放和备货的少数几款商品 |
| 长尾 | 不投广告、只吃自然流量的商品 |
| 奖惩中心 | 抖店违规管理入口（不是"处罚中心"） |
| 撤架 / 下架 | 把商品从在售变为下架 |
| OPC | One Person Company，一人公司 = 我的全部业务 |

## 我常用的缩写

| 缩写 | 全称/含义 |
|---|---|
| GMV | 成交总额 |
| ROI | 投入产出比（我说 ROI 时通常指广告 ROI） |
| CPS | 按成交付费 |
| SKU | 商品规格（一个商品下可能有多个 SKU） |
| CDP | 浏览器调试协议（AI 操作网页用的，我不用管） |

## 我希望 AI 统一使用的写法

<!-- AGENT-BLOCK:START kind=preference priority=high -->
- 金额：**¥29.98**（¥ 符号 + 两位小数）
- 日期：**2026-10-20**
- 涨跌配色：**涨=红色，跌=绿色**（中国习惯）
- 商品 ID：**写全 19 位数字**，不要简写
- 平台后台：写中文名 + 括号域名（例：奖惩中心 `fxg.jinritemai.com/ffa/govern-guarantee/regulation`）
- 表格优先，别用大段文字列对比
