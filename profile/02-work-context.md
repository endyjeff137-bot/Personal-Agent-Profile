- 主平台：**抖音小店（企业店）**
- 当前阶段：**起步期 0→1**（在售约 49 款，累计订单个位数）
- 核心指标我最在意：**净利润**，其次订单量
- 当前最大瓶颈：**流量**（0 单 → 体验分锁在成长阶段 → 被隐形限流 → 更难出单的死循环）
- 成本结构特点（**2026-11-03 v2 口径**，已修正三个错误，勿用旧口径手算）：
  - **定价公式**：
    ```
    GMV      = 售价 × 件数
    达人佣金 = GMV × 佣金率          ← 按 GMV 抽，不是毛利
    平台费   = GMV × 技术服务费率     ← 按比例，不是固定 3 元
    售后摊销 = GMV × 售后率
    运费     = 单件运费 × 件数       ← 按件，是变动成本，不摊薄
    包装     = 单件包装 × 件数

    每单净利 = GMV − 进货价×件数 − 佣金 − 平台费 − 售后摊销 − 运费 − 包装
    单件净利 = 每单净利 ÷ 件数

    正推（求最低售价）：售价 = (进货价 + 运费 + 包装 + M) ÷ (1 − 佣金率 − 平台费率 − 售后率)
    反推（求最高进货价）：进货价 = 售价 × (1 − 佣金率 − 平台费率 − 售后率) − 运费 − 包装 − M
    保本价（M=0）：保本价 = (进货价 + 运费 + 包装) ÷ (1 − 佣金率 − 平台费率 − 售后率)
    ```
  - 修正的三个错误：①佣金按毛利抽 → 应按 GMV ②平台费固定3元/单 → 应按比例（高价品低估 17~35 元/单）③运费按单摊薄 → 实为按件计
  - 参数：平台技术服务费率 **按类目分档**（2026-11-11 实测资金账单：低价类目 4.83% / 木薯猫砂 9.11% / 狗狗衣服 9.99%）。**不是固定 5%** — 做定价决策用最高档 10.5%，利润预估用实际档位 · 售后摊销率 2% · 运费 **6 元/件** · 包装 0.5 元/件 · 运费险 0.15 元/单 · 目标单件净利 0.5 元
  - **计费基数 = 买家实付（含平台补贴）**。账单列「订单实付应结」是已扣费净额，直接当基数会算错
  - **免佣**：11 月起账单不展示免佣信息，走【返佣管理】查
  - 旧口径（仅供理解历史决策）：「进货价+10元」= n=1、运费6.5/单 的特例。n=2 加 5.25，n=3 加 3.67
  - **唯一利润杠杆 = 每单件数**（旧口径下 1 件 0.5 / 2 件 10.5 / 3 件 20.5）
  - 现定价下**佣金空间 = 0**，达人分销数学上跑不通，必须先改运费结构
  - 运费 6.5 → 0.5 后：n=1 加价从 +10 降到 +4，**达人佣金空间从 0.9% 升到 12.1%**

## 行业常识（别让我听到外行话）

- **体验分口径（重要，别混用两套刻度）**：抖店体验分**满分 5 分**，前台显示 0–5 分。
  - **480** = 千分制换算值（4.8 分 × 100），是**隐形限流分水岭**
  - **70** = 百分制换算值（0.7 分 × 100），表示还在成长阶段
  - 两个数字说的是同一套分数的不同刻度。**判断时先换算回 5 分制**，别把 70 当百分制评分
- **低于 480（即低于 4.8 分）即隐形限流**：千川受限、商品卡流量收缩、大促不可报名，**平台不通知**
- 权重顺序：短视频种草 > 商城商品卡 > 搜索 > 直播直投
- 商品卡获客成本约为内容场的 **35%**
- 达人分销（精选联盟）是 **CPS 零风险**，是本店主推引擎
- 商城「猜你喜欢」入池需：体验分 ≥3 分（百分制 ≥60）、近 30 天违规 <3 次
- **删商品 ≠ 关闭违规预警单**，预警单必须回单内提交整改凭证才关
