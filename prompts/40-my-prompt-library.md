## 日常提问

- **让我快速懂一件事**
  ```
  用三段讲清楚 {{主题}}：①一句话结论 ②为什么 ③我现在该做什么。
  不要铺垫，不要问我"你想了解哪方面"。
  ```

- **让我做决定**
  ```
  我在纠结 {{A}} 和 {{B}}。给我一张对比表（成本/风险/耗时/效果），
  最后直接说你推荐哪个，并说明在什么情况下应该反过来选。
  ```

- **让我检查自己的方案**
  ```
  这是我的方案：{{...}}。
  请扮演一个反对我的人，找出 3 个最可能失败的地方，并给出补救办法。
  不要夸我。
  ```

## 工作类

- **拆解任务**
  ```
  把 {{目标}} 拆成可以当天执行的小步骤，每步标明：做什么、要多久、做完怎么验证。
  标出哪些步骤有不可逆风险。
  ```

- **算账**
  ```
  按我的成本结构算一下：{{场景}}。
  必须把计算过程写出来，并标出我最可能算漏的那一项。
  ```

- **写文案/标题**
  ```
  为 {{商品}} 写 {{N}} 个 {{平台}} 标题，要求：{{卖点}}。
  每条后面注明你用了什么套路，方便我判断。
  ```

## 与 AI 协作类

- **让 AI 不要啰嗦**
  ```
  从现在起，回答控制在 {{N}} 行内，结论先行，不要总结，不要复述我的问题。
  ```

- **让 AI 记住新偏好**
  ```
  记住：{{新偏好}}。这是长期有效的，以后默认遵守。
  顺便给我一行 Markdown，我好加进我的档案仓库。
  ```

- **让 AI 自查**
  ```
  你刚才的回答里，有哪些是事实、哪些是你的推断？分开列出来。
  ```

## 我给 AI 的"角色设定"常用句

- `你是一个{{}}，你说话的风格是{{}}。`
- `我不需要你安慰我，我需要你告诉我哪里错了。`
- `如果我的思路有问题，直接打断我。`
