## ⭐ 我最常用的四句（几乎每次都这么问）

### 1. 让它直接干，别给我选项

```
{{任务描述}}。直接做，做完告诉我结果和风险，不用先问我确认。
```

### 2. 让它别猜

```
信息不够就问我，不要用"一般来说"蒙。缺什么列出来。
```

### 3. 让它算账

```
按我的成本结构算：{{场景}}。
把每一步计算写出来，并指出我最可能算漏的那一项。
```

### 4. 让它反驳我

```
我这个想法{{...}}。直接说哪里不对，别夸我，别给我列一堆"优点"。
```

## 日常提问

- **让我快速懂一件事**
  ```
  用三段讲清楚 {{主题}}：①一句话结论 ②为什么 ③我现在该做什么。
  不要铺垫，不要问我"你想了解哪方面"。
  ```

- **让我做决定**
  ```
  我在纠结 {{A}} 和 {{B}}。给我一张对比表（成本/风险/耗时/效果），
  最后直接说你推荐哪个，并说明在什么情况下应该反过来选。
  ```

- **让我检查自己的方案**
  ```
  这是我的方案：{{...}}。
  请扮演一个反对我的人，找出 3 个最可能失败的地方，并给出补救办法。
  不要夸我。
  ```

## 抖店专用（电商场景）

- **选品评估**
  ```
  这个品 {{商品信息}}。按我的成本结构（进货价+10元，每单扣3平台+6.5运费），
  算出单件净利和每单件数盈亏平衡点，再判断值不值得上。
  ```

- **算 ROI 能不能投**
  ```
  千川计划 {{数据}}。按我的单件净利算保本 ROI。
  ROI 低于 {{X}} 就别投 —— 直接告诉我"不划算"和原因。
  ```

- **写挂车文案**
  ```
  给 {{商品}} 写 {{N}} 条抖音挂车文案，要求：{{卖点}}。
  每条后面注明你用了什么套路，方便我判断。
  避开违禁词和极限词。
  ```

- **批量改价前的熔断检查**
  ```
  我要改价这 {{N}} 款商品：{{列表}}。
  先检查是否触发我的硬规则（单日改价>5款、偏远限售、不删商品），
  有触发就先停下来告诉我。
  ```

- **每日复盘**
  ```
  今天的店铺数据：{{...}}。
  按"哪里超预期 / 哪里掉链子 / 明天改什么"三段输出，
  结论前置，不要罗列全部指标。
  ```

## 与 AI 协作类

- **让 AI 不要啰嗦**
  ```
  从现在起，回答控制在 {{N}} 行内，结论先行，不要总结，不要复述我的问题。
  ```

- **让 AI 记住新偏好**（← 这句最常用）
  ```
  记住：{{新偏好}}。这是长期有效的，以后默认遵守。
  顺便给我一行 Markdown，我好加进我的档案仓库。
  ```

- **让 AI 自查**
  ```
  你刚才的回答里，有哪些是事实、哪些是你的推断？分开列出来。
  ```

- **让 AI 加载我的档案**（换新 AI 时）
  ```
  读取 https://github.com/endyjeff137-bot/Personal-Agent-Profile 这个仓库，
  从 AGENT.md 开始，按里面的协议加载我的个人档案，然后只回一句"档案已加载"。
  ```
