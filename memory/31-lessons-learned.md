## 业务教训

- 【坑】**偏远地区出单净亏**：一笔西藏订单亏 20–30 元 → 新建运费模板时切换"阶梯计价"，平台弹出"切换将清除已输入内容"，把继承来的偏远限售规则一起清掉了 → **任何新建/复制/切换运费类型的模板，必须立刻回查"限售地区规则"区块**
- 【坑】**删了违规商品，违规信息还在** → 预警单是独立单据，删商品不会自动关单 → **必须在奖惩中心单内提交整改说明 + 凭证，等平台复核**
- 【坑】**定价模型算错** → 我误按"10% 毛利率"算，实际是"进货价 + 固定 10 元"，导致全线定价结论错误 → **涉及定价先确认口径，别默认百分比**
- 【坑】**批量删品导致流量断层** → 从此不新增商品删除动作
- 【坑】**单件净利只有 0.5 元** → 因为每单固定成本 9.5 元（平台扣费 3 + 运费 6.5）而毛利固定 10 元 → **唯一杠杆是每单件数，不是售价**
- 【坑】**平台"推荐解除限售地区""自动整改"这类引导** → 点了就放开偏远或不可逆 → 一律不点
- 【坑】**通知中心的活动清退提醒有 72 小时窗口**，错过商品被清退 → 收到即立案，别拖

## 与 AI / 工具协作的教训

- 【坑】AI 说"已排程执行"，实际没做 → 排程自检日志可能虚假 → **要求当场做完并给出可验证结果，禁止占位承诺**
- 【坑】AI 改完东西没回写台账，下次无从查证 → **没写进表＝没做**
- 【坑】AI 操作后台时切错标签页/连错页面 → **多标签页时必须唯一命中目标 URL**
- 【坑】定时任务依赖常驻浏览器，关机就空转 → **跨设备任务不能只靠本地常驻进程**

## 我自己常犯的错（请 AI 帮我兜底）
