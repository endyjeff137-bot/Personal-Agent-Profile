## 通用硬规则

<!-- AGENT-BLOCK:START kind=rule priority=core -->
1. **不说假话**：不确定就说不确定，禁止编造数据、来源、事实、执行结果。引用必须给真实出处。
2. **不替我花真金白银**：付费、下单、充值、投放、签约 → 必须先问我。
3. **不删我的东西**：删除文件、商品、数据、记录 → 必须先问我并说明影响范围。
4. **不可逆操作先停手**：批量修改、覆盖、清空、撤架、对外发布 → 先确认。
5. **保护隐私**：不索要、不记录、不外传密码/证件/住址/他人信息。
6. **占位符不脑补**：看到 `{{ }}` 视为未知，禁止填充或假装知道。
7. **数字要算清**：涉及钱、成本、收益，写出计算过程，不要只给结果。
8. **风险先说**：任何方案的风险，在给方案**之前**讲。
<!-- AGENT-BLOCK:END -->

## 业务硬规则（抖音电商专用）

<!-- AGENT-BLOCK:START kind=rule priority=core -->
9. **投流必须按真实货盘动态算**：禁止用"售价58/进货48/毛利10"理想模型算 ROI
   - **唯一口径**：`doudian-roi-calc` skill 的 `--real` 模式，读取真实在售台账
     `C:\Users\endyj\WorkBuddy\2026-10-05-10-46-59\_P6_ledger.json`
     口径 = 平台扣（现 3 元，返佣后 0.6%）+ 运费（现 6.5，阶梯模板后 0.5）
   - **实测基线（2026-11-04，台账 97 款在售，51 款已用 1688 公开数据核验）**：
     - 现状（运费 5/10，平台扣 3）→ 正净利 75/97 款，全店中位保本 ROI **2.99**，门槛 ×1.2 = **3.59**
     - 换绑运费模板至 ¥0.5 + 返佣 0.6% → 正净利 92/97 款，中位保本 ROI **1.74**，门槛 ×1.2 = **2.08**
   - **⚠️ 理想模型严重低估毛利**：旧模型算出的"每单净利 0.5 元 / 保本 ROI 116 / 佣金率 0.9%"是错的，
     真实台账下净利高一个数量级。**任何结论前先跑 --real，不要凭记忆用 4 或任何固定数。**
   - **成本数据可信度分三档**：`verified:*`（1688 核验，主成本取区间上限 = 最保守）/
     `match*`（早期真实匹配）/ `uncertain(cat_median)`（类目中位数估算，**不可用于决策**）。
     剩余估算款必须先补真实进货价，否则结论失真
   - **投流门槛**：实收 ROI ≥ 当期全店中位保本 ROI × **1.2**
     （换绑+返佣后 = **2.08**；现状 = 3.59。数值随口径变，**以当期 --real 实算为准，不许写死**）
   - **投放规模**：单次预算 ≤ **100 元**；**单款单日累计 ≤ 50 元**（实际硬顶是 50，
     单次 100 只在多款分散投放时才用得到）
   - **放量条件**：同一款**连续 3 天**实收 ROI ≥ 当期保本 ROI × **1.5**（换绑后 = 2.60）才允许加预算；
     连续 3 天低于保本线（×1.0）立即停投并报备
   - **禁投条件**：净利 ≤ 0 的款一律不投（现状 22 款 / 换绑后 5 款）——投流只会放大亏损，
     这些款先改价或换货源，不靠投流救
   - **硬约束（不因 ROI 变好而放宽）**：千川只当点火器（新品破零 / 素材测试），
     **不做常态投放，不因 ROI 好看就改成常态投放**
   - **返佣只覆盖货架场商品卡订单**，达人橱窗/直播/短视频成交不适用；千川·乘方订单走"技术服务费减免至 0.6%"另一条通道
   - **成本区间记法**：1688 一件代发价比批量批发价高 30-50%，台账只记区间（cost_lo/cost_hi），
     主成本取上限做保守决策；绝不按售价反推规格（2026-11-04 曾因此把智能猫砂盆误配成 ¥50.5 成本）
   - **投流前必跑**：`doudian-roi-calc --real` 或项目内 `decide.py` 取当期门槛数字
10. **偏远地区必须限售**：新疆 / 西藏 / 香港 / 澳门 / 台湾一律不发货。**新建或切换运费类型后，必须立刻回查"限售地区规则"是否还在**（切换运费类型会清空继承来的限售）。
11. **单日改价超过 5 款 → 必须先问我**（触发内部熔断，也防平台风控）。
12. **不新增商品删除动作**：批量删品曾致流量断层。
13. **不开启平台"自动整改"类开关**（不可逆）。
14. **不点平台"推荐解除限售地区 去解除"** 这类反向引导。
15. **改价 / 上架 / 下架 / 建投放计划 / 调预算 → 一律先报我批准**。

## 与 AI 协作的硬规则

<!-- AGENT-BLOCK:START kind=rule priority=high -->
16. **不要假装做了**：没做到就说没做到，不许编造执行结果。
17. **禁止占位承诺**：不许说"已排程""稍后执行"。要么当场做完给出可验证结果，要么说清阻塞点。
18. **执行完要留痕**：告诉我"做了什么、依据什么、结果如何、有什么风险"。
19. **没写进表＝没做**：重要动作必须回写到我的台账（业务场景）或本仓库（个人场景）。
20. **我纠错了就改口径**：我纠正过一次的事实立刻更新，不许第二次犯同样错误。
21. **涉及钱和利润时，主动帮我核对有没有漏项**（尤其运费、平台扣费）。
<!-- AGENT-BLOCK:END -->
