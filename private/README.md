## 这个目录是干什么的

一个**占位提醒**。放在这里的内容：

- 只存在于**你自己的电脑**上
- 已被 `.gitignore` 排除，**永远不会 `git push` 到 GitHub**
- 供本地 Agent / 脚本读取；云端 AI 一律不给

**用法**：把敏感信息写进 `private/` 下的文件，然后在公开仓库的对应位置只写"类型"。

| 公开仓库写法 ✅ | 本地 private 写法 🔒 |
|---|---|
| `我的店铺主营 {{宠物用品}}，平台 {{抖音小店}}` | `店铺名：拓泽智贸爱宠用品市集；账号：xxx` |
| `单件毛利约 {{10}} 元` | `进货价明细表：见 cost.xlsx` |
| `我在 {{广东珠海}}` | `发货地址：珠海市xx区xx路xx号` |
| `供应商合作中` | `供应商：XXX，联系人微信 xxx，账期 30 天` |

## ⛔ 绝对不要上传到 GitHub 的清单

每次 commit 前扫一眼：

### 凭据类
- [ ] 密码、PIN、支付密码
- [ ] API Key、Secret、Token、Access Key
- [ ] 私钥文件（`.pem`、`.key`）、SSH 私钥
- [ ] `.env`、`.env.local` 等配置文件
- [ ] 2FA 恢复码、验证码、备份码
- [ ] Cookie、Session、浏览器登录态数据

### 证件与身份
- [ ] 身份证号 / 护照号 / 社保号 / 驾驶证号
- [ ] 银行卡号、CVV、网银 U 盾信息
- [ ] 营业执照原件照片、公章照片
- [ ] 人脸、指纹等生物特征

### 住址与行踪
- [ ] 家庭住址、门牌号、仓库地址（发货地可写到"市"）
- [ ] 常去地点、通勤路线
- [ ] 出差/旅行行程、机票酒店订单
- [ ] 孩子的学校、老人的住址

### 他人信息
- [ ] 家人 / 同事 / 客户的真名 + 手机 + 微信 + 地址
- [ ] 聊天记录、通话录音原文
- [ ] 他人的照片、隐私信息
- [ ] 员工薪资、人事评价

### 商业敏感
- [ ] 进货价、成本表、供应商报价单
- [ ] 客户名单、联系方式、成交金额
- [ ] 合同全文、未公开财务数据
- [ ] 未发布的产品、配方、方案
- [ ] 税务申报细节

### 个人敏感
- [ ] 病历、体检报告、用药记录
- [ ] 心理咨询记录
- [ ] 政治立场、宗教信仰、性取向
- [ ] 法律纠纷、诉讼材料
- [ ] 情绪崩溃时的私人文字（除非你想让 AI 看到）

## 自检三问

commit 之前问自己：

1. **这句话被一个陌生人看到，我会不会后悔？** → 会就不传
2. **如果 GitHub 账号被盗，这个信息会不会害到我？** → 会就不传
3. **这个信息 AI 真的需要吗？还是我只是顺手写的？** → 不需要就不传

---

## 已经误传了怎么办

1. **立刻改掉**：先去改密码 / 吊销 Key（改仓库内容没用，Git 历史还在）
2. **清理历史**：GitHub 仓库 → Settings → 危险区 → 或用 `git filter-repo` 重写历史
3. **最快止损**：如果是 Private 仓库误转 Public，先转回 Private，再慢慢清历史
4. **记住**：Public 仓库的内容可能已被爬虫抓取，删除不等于消失

├── identity.local.md         真实姓名、证件类型（不写号码）
